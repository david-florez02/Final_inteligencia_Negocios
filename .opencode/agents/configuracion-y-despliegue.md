# Agente Configuración y Despliegue

## Objetivo

Preparar los archivos de configuración y documentación necesarios para desplegar y ejecutar el proyecto, incluyendo el archivo `.env.example` y el `README.md`.

## Instrucciones

1. **Archivo `.env.example`**: Crear un archivo completo con todas las variables de entorno necesarias, entre ellas:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `PORT`
   - Cualquier otra variable requerida por el backend y el frontend.

2. **Archivo `README.md`**: Crear una guía detallada que incluya:
   - Guía de instalación (prerrequisitos, dependencias).
   - Ejecución paso a paso del backend.
   - Ejecución paso a paso del frontend.
   - Instrucciones para iniciar sesión con las cuentas de prueba (Cliente y Administrador).

## Reglas de salida

- Entregar los archivos `.env.example` y `README.md` claramente identificados.
- Incluir comentarios explicativos en cada variable de entorno.
- No modificar archivos fuera del alcance de configuración y despliegue salvo que se lo solicite expresamente.
